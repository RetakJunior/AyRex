AyRex third-party software notices

scap 0.1.0-beta.1 (locally patched)
--------------------
AyRex uses scap for Wayland desktop capture through the XDG Desktop Portal and
PipeWire. The vendored source restricts PipeWire negotiation to BGRx, the only
format consumed by AyRex's FFmpeg input. The MIT license is included in
scap-MIT.txt.
Upstream source: https://github.com/helmerapp/scap

libspa 0.8.0 (locally patched)
-----------------------------
PipeWire's Rust SPA bindings are vendored to keep the PipeWire builder storage
layout compatible with both Ubuntu 22.04 and newer PipeWire headers. The MIT
license is included in libspa-MIT.txt.
Upstream source: https://gitlab.freedesktop.org/pipewire/pipewire-rs

wasapi-rs 0.26.0
----------------
AyRex links the Rust WASAPI bindings by Henrik Enquist for Windows system audio
loopback capture. The license is included in wasapi-MIT.txt.
Upstream source: https://github.com/HEnquist/wasapi-rs

FFmpeg
-------
The portable Windows package includes a separate FFmpeg executable and its
adjacent runtime libraries from Gyan.Dev's Windows build. The Linux AppImage includes
FFmpeg from the Ubuntu 22.04 distribution packages and its dependent shared
libraries. Both include GPL-licensed components including libx264. FFmpeg
remains a separate process and is not linked into the AyRex executable.

FFmpeg project and source code:
  https://ffmpeg.org/
  https://ffmpeg.org/download.html
Windows build provider and build information:
  https://www.gyan.dev/ffmpeg/builds/
FFmpeg licensing:
  https://ffmpeg.org/legal.html
GPL version 3:
  https://www.gnu.org/licenses/gpl-3.0.html

The package also contains the GPLv3 license text and the exact FFmpeg version
string used to build it. The FFmpeg executable and its components are
distributed under their respective upstream licenses. Corresponding sources
and build information are available from the linked FFmpeg and build-provider
pages. AyRex's own source code and logo are maintained separately in the AyRex
repository.
